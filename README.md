# OOP_Labs

Лабораторні роботи з Об'єктно-орієнтованого програмування, КПІ ім. Ігоря Сікорського

**Студент:** Мащута Олександр, ІМ-051, 121 «Інженерія програмного забезпечення»
**Викладач:** Рекечинський Дмитро Олександрович

## Лабораторні

Кожна наступна лабораторна робота продовжує попередню, в результаті чого створюється комплексний графічний редактор об'єктів.

| № | Лаба | Тема | Статус |
|---|------|------|--------|
| 1 | [lab1](./labs/lab1) | WinForms, модульний проєкт, діалогові вікна | ✅ Готова |
| 2 | [lab2](./labs/lab2) | Ієрархія класів Shape, поліморфізм, малювання фігур | ✅ Готова |
| 3 | [lab3](./labs/lab3) | Toolbar, tooltips, синхронізація інтерфейсу | ✅ Готова |
| 4 | [lab4](./labs/lab4) | Рефакторинг, MyEditor, C#-аналог множинного успадкування | ✅ Готова |
| 5 | [lab5](./labs/lab5) | Singleton Меєрса, багатовіконний інтерфейс, збереження в файл | ✅ Готова |
| 6 | [lab6](./labs/lab6) | IPC (WM_COPYDATA), Clipboard, розподілена система з 3-х додатків | ✅ Готова |

**Легенда:** ⬜ Не почата | 🔄 В процесі | ✅ Готова

В кожній папці `labN/` міститься вихідний код та звіт у папці `report/`.

## Результат

Усі 6 лабораторних робіт реалізовані у вигляді графічного редактора об'єктів:
від простого модульного WinForms-додатка (Lab 1) до розподіленої системи
з трьох незалежних програм (Lab 6), що обмінюються даними через `WM_COPYDATA` та `Clipboard`.
